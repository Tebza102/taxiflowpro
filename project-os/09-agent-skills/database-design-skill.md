# Database Design Skill

## Purpose
Use this skill when designing or changing database structures.

## Required Reading
- `/project-os/04-technical/data-model.md`
- `/project-os/04-technical/auth-and-roles.md`
- `/project-os/06-quality/security-checklist.md`

## Process
1. Identify entities.
2. Define relationships.
3. Define required fields.
4. Define validation rules.
5. Define access rules.
6. Consider migration risks.

## Output Required
- Proposed schema
- Access rules
- Risks
- Migration plan
- Test plan
