# UI Patterns

## Layout Principles
- Mobile-first where users are likely to work from phones.
- Clear dashboard hierarchy.
- Strong empty states.
- Visible primary action per page.
- Avoid overcrowded screens.

## Common Components
List reusable buttons, cards, tables, forms, modals, sidebars, navbars, drawers, charts, badges, and alerts.

## Interaction Rules
- Forms must show clear validation.
- Loading states must be visible.
- Errors must explain what the user can do next.
- Dangerous actions require confirmation.

## Accessibility Rules
- High contrast text.
- Keyboard accessible forms.
- Labels for fields.
- Avoid colour-only communication.

## Responsive Rules
Describe how tables, dashboards, cards, and navigation behave on mobile.
