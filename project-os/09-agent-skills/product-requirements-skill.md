# Product Requirements Skill

## Purpose
Use this skill to turn a business idea into product requirements.

## Required Reading
- `/project-os/01-business/business-case.md`
- `/project-os/02-product/mvp-scope.md`
- `/project-os/02-product/user-journeys.md`

## Process
1. Identify must-have features.
2. Remove non-essential features.
3. Define user journeys.
4. Define acceptance criteria.
5. Identify dependencies.

## Output Required
- Feature list
- User flows
- Acceptance criteria
- Out-of-scope items
- Implementation priority
