# Digital Stationery Design Skill

## Purpose
Use this as a website-to-business-stationery agent for:
- letterhead
- invoice templates
- quotation templates
- business/company profiles
- proposal and capability templates
- slide deck templates
- email signatures
- social media profile/banner/post templates
- procurement-ready document systems

If a website exists, extract brand direction from it first. Do not start from scratch.

## Required Reading Before Work
1. `/project-os/03-design/brand-rules.md`
2. `/project-os/03-design/ui-patterns.md`
3. `/project-os/03-design/content-guidelines.md`
4. `/project-os/09-agent-skills/reference-art-direction-skill.md`
5. `/project-os/07-agent-control/agent-rules.md`

## Website Extraction Requirements
Extract:
1. business name
2. brand positioning
3. primary message
4. hero tone
5. services/products
6. target audience
7. CTA style
8. color system
9. typography mood
10. spacing and hierarchy style
11. trust and credibility signals
12. contact/footer structure

## Brand Consistency Engine
Define before outputs:
- Brand DNA
- color rules
- typography rules
- logo placement rules
- header/footer rules
- spacing rules
- table style for invoices/quotes
- slide rhythm rules
- social template rules

## Compliance Rules
Never invent legal/banking/compliance data. Mark unknown values as `Required from client/user`.

Check/request:
- legal business name
- registration/VAT/tax/CSD/B-BBEE fields where relevant
- contact details and address
- banking/payment terms for invoices/quotes
- quote validity and invoice due terms
- signature/approval fields
- terms/disclaimer/POPIA notes where relevant

## 3D Usage Rule
Use `3d-design-skill.md` only for optional mockups, cover visuals, social campaign assets, or presentation visuals.
Do not force 3D into procurement or compliance documents where clarity is primary.

## Anti-Generic Rules
Avoid:
- generic Canva template look
- random gradients
- excessive boxes/cards
- inconsistent logo placement
- weak alignment or tiny unreadable text
- over-decorated procurement documents

## Required Output Format
1. Skill used
2. Source website/reference reviewed
3. Website brand system extracted
4. Asset list
5. Compliance fields required
6. Missing information
7. Per-asset design plan
8. Copy-paste content structure
9. Design-tool prompt
10. Export/handover notes
11. Quality checklist
12. Remaining risks
