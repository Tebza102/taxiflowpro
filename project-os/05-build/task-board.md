# Task Board

## Backlog
- Task not yet ready.

## Ready
- Task ready for planning.

## In Progress
- Task being worked on.

## Review
- Task awaiting human review.

## Done
- Completed task.

## Blocked
- Task blocked and reason.

## Task Format
Each task should include:
- Purpose
- Files likely involved
- Risk level
- Test required
- Definition of done
