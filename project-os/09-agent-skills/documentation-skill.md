# Documentation Skill

## Purpose
Use this skill to create or improve documentation for developers, clients, users, or future AI agents.

## Process
1. Identify audience.
2. Identify purpose.
3. Use simple structure.
4. Include steps, warnings, and expected results.
5. Avoid unnecessary technical language for non-technical users.
6. Link to relevant Project OS files.

## Output Required
- Document created/updated
- Audience
- Key sections
- Remaining gaps
