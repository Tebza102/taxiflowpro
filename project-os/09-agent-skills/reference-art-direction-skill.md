# Reference Art Direction Skill

## Purpose
Use this skill when a reference website, screenshot, flyer, or video is provided and direction must be adapted without copying.

## Core Rule
Reference-first analysis, brief-obedient adaptation, no cloning.

## Required Reading Before Work
1. `/project-os/00-start-here/project-brief.md`
2. `/project-os/00-start-here/current-status.md`
3. `/project-os/02-product/product-requirements.md`
4. `/project-os/03-design/brand-rules.md`
5. `/project-os/03-design/content-guidelines.md`
6. `/project-os/07-agent-control/agent-rules.md`

## Mandatory Extraction
Extract:
1. layout structure
2. spacing rhythm
3. typography mood
4. color behavior
5. image treatment
6. motion style if relevant
7. visual hierarchy
8. emotional tone
9. what is distinctive
10. what must not be copied
11. whether the reference uses 3D, depth, texture, illustration, or spatial composition

## 3D Escalation Rule
If 3D language is central to the reference, use `3d-design-skill.md` for scene/material/camera direction before output generation.

If references are scroll-animated, canvas-sequenced, cinematic, or video-led web experiences, trigger `video-to-website-skill.md`.

## Anti-Generic Rule
Do not replace strong references with generic template layouts.

## Required Output
- reference extraction summary
- adaptation map for this brand/project
- direction statement
- layout and hierarchy plan
- 2D/3D usage decision
- risks and dependencies
