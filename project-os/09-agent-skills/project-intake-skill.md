# Project Intake Skill

## Purpose
Use this skill when starting a new project or reviving an old project.

## Required Reading
- `/project-os/00-start-here/project-brief.md`
- `/project-os/01-business/business-case.md`
- `/project-os/02-product/mvp-scope.md`

## Process
1. Identify the business goal.
2. Identify the primary user.
3. Define the MVP outcome.
4. List risks and unknowns.
5. Define the first safe action.

## Output Required
- Project summary
- Target user
- Core problem
- MVP scope
- Top risks
- First 5 actions
