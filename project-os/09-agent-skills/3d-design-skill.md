# 3D Design Skill

## Purpose
Use this skill for 3D design direction and 3D asset prompting across:
- 3D product mockups
- 3D logo scenes
- 3D website hero visuals
- 3D social media assets
- 3D stationery mockups
- 3D icons
- 3D brand environments
- 3D motion scenes
- 3D video prompts
- isometric business illustrations
- spatial UI concepts
- Spline-style web scenes
- Three.js/WebGL creative direction
- Blender-style render prompts
- cinematic product reveal scenes
- 3D explainer visuals

3D render sequences from this skill can be used as source material for `video-to-website-skill.md` when building video-led scroll websites.

## Core Rule
Use 3D only when it supports the message, product clarity, brand memorability, or conversion objective.
If 3D does not serve the brief, do not use it.

## 3D Decision Rule (Mandatory)
Before using 3D, answer:
1. Does 3D help explain, sell, or elevate the brand?
2. Is 3D requested or supported by the reference?
3. Will 3D reduce clarity or improve memorability?
4. Can it be executed cleanly?
5. Is a simpler 2D/editorial solution better?

## Extraction Requirements
Extract before creating prompts or concepts:
- business context
- brand identity
- purpose of the 3D element
- target audience
- platform/output format
- visual reference
- object/subject focus
- material style
- lighting direction
- camera angle
- environment
- motion requirements if relevant
- realism level
- brand colors
- logo/text stability needs
- what must not distort
- handover/export format

## 3D Style Modes
Choose one primary mode unless the brief requires blending:
- realistic product render
- cinematic 3D
- stylized 3D
- isometric business illustration
- clay/rendered minimal
- premium corporate 3D
- technical/industrial 3D
- Afrocentric geometric 3D
- spatial web scene
- motion-graphics 3D

## Safety and Quality Rules
Do not:
- invent copyrighted logos
- distort brand marks
- create unreadable 3D text
- warp faces or hands
- create random meaningless objects
- overuse glossy fake SaaS 3D

3D must support the story and brand objective.
Brand accuracy is more important than visual flash.

## Required Output
1. Brief interpretation
2. 3D objective
3. Brand relevance
4. 3D style direction
5. Scene/object description
6. Materials and textures
7. Lighting plan
8. Camera/composition plan
9. Motion plan if applicable
10. Platform/export recommendation
11. AI image/video/3D tool prompt
12. Negative prompt
13. Quality checklist
14. Handover notes

## Quality Checklist
Before finalizing, verify:
- 3D serves the brief
- brand identity is preserved
- text/logos remain stable and readable
- materials, lighting, and camera are coherent
- style mode is clear
- output is practical for the target tool/platform
- scene is not generic or decorative-only

## Stop Conditions
Stop and ask for clarification if:
- required brand assets are missing
- the brief and reference conflict
- realism level is unclear for the output context
- legal or copyright risk is unresolved
