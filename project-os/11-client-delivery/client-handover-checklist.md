# Client Handover Checklist

## Before Handover
- [ ] Final scope confirmed.
- [ ] Main workflow tested.
- [ ] Login details prepared if applicable.
- [ ] Deployment live.
- [ ] Domain connected.
- [ ] Client content checked.
- [ ] Known limitations documented.

## Handover Materials
- [ ] Client guide
- [ ] Admin guide
- [ ] Support terms
- [ ] Maintenance plan
- [ ] Invoice/payment status
- [ ] Access list

## After Handover
- [ ] Client confirms access.
- [ ] Client confirms core workflow.
- [ ] Support window begins.
- [ ] Testimonial/referral request scheduled.
