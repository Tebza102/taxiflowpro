# Graphic Design Skill

## Purpose
Use this skill for posters, flyers, campaign visuals, social graphics, brand assets, one-pagers, and presentation visuals.

## Core Rule
Graphic direction must be brief-first, reference-aware, and brand-specific. Do not output generic AI poster styles.

1. `/project-os/00-start-here/project-brief.md`
2. `/project-os/00-start-here/current-status.md`
3. `/project-os/02-product/product-requirements.md`

5. `/project-os/03-design/content-guidelines.md`

## Anti-Generic Rules
Avoid:
- generic Canva/template poster look
- random gradients and glow effects
- weak typographic hierarchy
- filler icon packs
- over-decorated layouts

## 3D Integration Rule
Use `3d-design-skill.md` when work includes:
- 3D mockups
- 3D social assets
- 3D poster visuals
- 3D brand environments

Do not force 3D when 2D is clearer for the brief.

## Required Output
For planning:
- brief interpretation
- reference extraction
- creative direction
- composition and typography plan
- what to avoid

For implementation:
- files changed
- visual changes
- 2D/3D decision rationale
- quality checks
- remaining risks
