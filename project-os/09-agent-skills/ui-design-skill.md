# UI Design Skill

## Purpose
Use this skill for UI direction across websites, landing pages, web apps, dashboards, and client demos, with strict non-generic design discipline.

## Core Rule
Design must be brief-led and reference-aware. Do not default to template aesthetics.

## Anti-Generic Rules
Avoid:
- endless cards
- creamy white SaaS defaults
- repetitive rounded panels
- random gradients
- generic icon rows
- boxed text everywhere
- stock-template structure

## Escalation Rules
Escalate to:
- `frontend-design-skill.md` for distinctive frontend interfaces, scroll-driven pages, cinematic hero sections, and strong layout choreography
- `reference-art-direction-skill.md` when the user provides references that must drive visual direction
- `3d-design-skill.md` when 3D visuals, spatial depth, or 3D brand scenes are requested

## Required Design Checks
Before finalizing, verify:
- follows brief
- follows reference direction when provided
- hierarchy is clear
- typography leads structure
- card usage is intentional
- design feels brand-specific without a logo swap test

## Required Output
For planning:
- brief interpretation
- reference analysis
- UI direction
- layout hierarchy plan
- what to avoid

For implementation:
- files changed
- UI changes made
- how generic patterns were avoided
- responsive/accessibility checks
- remaining risks
