# Support Process

## Support Channels
List WhatsApp, email, ticket system, or call process.

## Response Expectations
Define what is included and what requires paid support.

## Issue Priority
| Priority | Description | Response Approach |
|---|---|---|
| Critical | System unusable | Immediate investigation |
| High | Major workflow broken | Prioritised fix |
| Medium | Partial issue | Scheduled fix |
| Low | Cosmetic or improvement | Backlog |

## Support Log Rules
Every support issue should be logged in `/project-os/08-logs/bug-log.md` or a client support log.
