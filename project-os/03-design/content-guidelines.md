# Content Guidelines

## Voice and Tone
Describe how the product speaks.

## Writing Rules
- Clear before clever.
- Explain actions in simple language.
- Avoid vague button text.
- Use helpful error messages.

## CTA Rules
Primary calls-to-action should be direct and outcome-based.

## Empty State Rules
Every empty state should explain what is missing and what the user should do next.

## Error Message Rules
A useful error message should include what happened, why it may have happened, and what the user can try next.
