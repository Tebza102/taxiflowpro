# Sales Proposal Skill

## Purpose
Use this skill to turn a product or project into a client-facing offer, proposal, pitch, or sales narrative.

## Required Reading
- `/project-os/01-business/business-case.md`
- `/project-os/01-business/offer-and-pricing.md`
- `/project-os/02-product/mvp-scope.md`

## Process
1. Identify the buyer.
2. Identify the pain point.
3. Translate features into business outcomes.
4. Define offer scope.
5. Define implementation timeline.
6. Define pricing logic.
7. Include risk reducers such as support, milestones, and proof.

## Output Required
- Sales angle
- Offer structure
- Proposal outline
- Pricing options
- Next-step CTA
