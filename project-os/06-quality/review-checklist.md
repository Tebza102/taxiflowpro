# Review Checklist

Use this before accepting any agent work.

## Scope Control
- [ ] Did the agent only change approved files?
- [ ] Did the agent avoid unrelated refactors?
- [ ] Did the agent avoid duplicate components/services/hooks?

## Code Quality
- [ ] Code is readable.
- [ ] Naming is consistent.
- [ ] Errors are handled.
- [ ] Loading states are handled.
- [ ] Mobile layout still works.

## Project OS Updates
- [ ] Change log updated.
- [ ] Bug log updated if relevant.
- [ ] Decision log updated if a major choice was made.
- [ ] Current status updated if project state changed.
