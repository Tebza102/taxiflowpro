# Frontend Build Skill

## Purpose
Use this skill for UI pages, components, forms, dashboards, and frontend flows.

## Required Reading
- `/project-os/03-design/ui-patterns.md`
- `/project-os/04-technical/architecture.md`
- `/project-os/07-agent-control/agent-rules.md`

## Process
1. Search for existing components.
2. Reuse existing layout and styles.
3. Build the smallest complete feature.
4. Handle loading, empty, success, and error states.
5. Test mobile and desktop.

## Output Required
- Files changed
- Components reused
- New components created
- Tests run
- Remaining risks
