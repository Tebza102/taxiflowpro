# Backend Build Skill

## Purpose
Use this skill for APIs, server actions, functions, validation, business logic, and integrations.

## Required Reading
- `/project-os/04-technical/architecture.md`
- `/project-os/04-technical/data-model.md`
- `/project-os/06-quality/security-checklist.md`

## Process
1. Identify existing backend patterns.
2. Validate inputs.
3. Protect sensitive actions.
4. Handle errors safely.
5. Return clear response formats.
6. Avoid exposing secrets.

## Output Required
- Endpoint/function changed
- Validation added
- Security considerations
- Tests run
- Risks
